Hosting a client website? Start here
  1. Add the website. Choose static files or a Node.js app, then upload your ZIP.
  2. Publish a version. Follow the next action on the website card. Node.js apps need a build first.
  3. Connect the client’s domain. Open Domains on the website card, add the DNS records, and verify ownership.
  4. Invite collaborators carefully. Team access applies to every website in this workspace. Separate client-only access is not available yet.
